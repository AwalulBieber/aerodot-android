# AeroDot

A native Android crosshair overlay and gaming utility app.

## Planned features
- Customizable floating crosshair overlay
- Crosshair preset library and profiles
- Aim Trainer
- Reaction Test
- Tap Speed / CPS Test
- Ping Checker
- Notification quick controls

## Tech stack
- Kotlin
- Jetpack Compose
- Android WindowManager overlay API
- DataStore / Room (planned)

## Requirements
- Android 8.0 (API 26) or newer
- Android Studio with Android SDK

## Build
Open this repository in Android Studio, allow Gradle sync, then run the app configuration.

AeroDot is an independent implementation. JFF Crosshair Pro is used as a feature reference; its source code and assets are not copied.
